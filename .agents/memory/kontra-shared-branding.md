name: Kontra shared branding asset
description: Canonical platform lockup used by the live public header and preparation PDF artifacts
---

The live public header and preparation PDF artifacts must consume the same canonical Kontra platform lockup asset. The legacy split-wordmark raster files are not authoritative.

**Why:** The PDF previously drifted from the live product by drawing or embedding a visually different wordmark, which made the external artifact look unofficial.

**How to apply:** When branding changes, update the shared lockup source and its PDF-safe companion together; do not draw or typeset the wordmark inside the PDF renderer.
