A successful AI replacement must become authoritative across summaries, Transaction Record fields, conflicts, readiness, tasks, and next actions in the same processing flow; superseded rows remain audit history only.

**Why:** Saving a replacement analysis without rerunning structured extraction leaves the Documents tab newer than Overview, allowing stale proceeds, repair costs, and conflicts to remain live.

**How to apply:** After active-version persistence, extract from the replacement's actual text, rebuild cross-document verification using only active versions, then recalculate Transaction Record state and tasks. Preserve confirmed values and represent new contradictions as reviewable conflicts.
